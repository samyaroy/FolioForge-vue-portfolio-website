# Production Audit — samyabrata.codeium.xyz

**Date:** 2026-08-06
**Target:** https://samyabrata.codeium.xyz
**Commit audited:** `5bade57` (main) / `44a32f5` (V1) — identical trees

## Method & limitations

HTTP-level inspection of the live site: response headers, served HTML, asset
payloads, redirect chains, `robots.txt`, `sitemap.xml` — cross-referenced
against the source tree.

**No headless browser was available.** Anything requiring a rendering engine
(console errors, measured CLS, keyboard traversal, computed contrast ratios,
paint timings) is marked **UNVERIFIED** rather than estimated. Lighthouse
figures at the end are explicitly labelled as projections, not measurements.

Every finding below has a reproducible command behind it.

---

## Remediation log

Findings below are recorded **as audited** at `5bade57`. Fixes applied since are
tracked here rather than by editing the findings, so the original evidence stays
intact.

### 2026-08-06 — bundle optimisation (§2, §5)

Applied route-level code splitting, Vuetify tree-shaking, and bundle analysis.

| | audited | after | change |
|---|---|---|---|
| Entry JS (gzip) | 344,001 b | **160,242 b** | **-53%** |
| Entry JS (raw) | 1,115,557 b | 468,684 b | -58% |
| Entry CSS (gzip) | 122,912 b | **95,917 b** | **-22%** |
| Entry CSS (raw) | 862,447 b | 648,877 b | -25% |
| Initial payload (gzip) | 466,913 b | **256,159 b** | **-45%** |
| JS chunks | 1 | 26 | |
| CSS chunks | 1 | 13 | |

Total JS across *all* chunks fell from 1,115,557 b to 796,247 b raw — roughly
320 KB was **eliminated** by tree-shaking, not merely deferred. Route splitting
then moves a further ~330 KB off the entry chunk.

What changed:

- `main.ts` no longer does `import * as components from 'vuetify/components'`;
  `vite-plugin-vuetify({ autoImport: true })` resolves components and their
  styles per usage. This is the source of both the JS and the CSS saving.
- All 15 routes in `src/router/index.ts` converted to `() => import(...)`.
- `npm run analyze` (`ANALYZE=1 vite build`) emits `bundle-report.html` at repo
  root — deliberately **not** into `dist/`, where it would be published with
  the site and hand a reader a complete map of the bundle. `open: false` so
  headless and CI builds do not break.

Verified unaffected: all 14 Vuetify components still bundled, 12 prerendered
route HTMLs, 12-URL sitemap, `404.html`, canonical tags, typecheck.

**Still outstanding from §2:** the MDI font (3.2 MB across four formats) is
untouched, and is the bulk of the remaining 648 KB of CSS. Deferred because 130
distinct `mdi-*` tokens are referenced across 61 files, 3 of which are YAML
*content* files (`ribbon.yml`, `facts.yml`, `resources.yml`) where icon names
are runtime data and therefore cannot be statically imported by `@mdi/js`.

**Unaffected by this work:** the empty `<body>` (§1) is an SEO problem, not a
bundle-size one. No change.

### Config contradicted by production

`wrangler.jsonc` sets `html_handling: "drop-trailing-slash"` and carries this comment:

> Serve /contact from /contact/index.html directly. The default
> (auto-trailing-slash) instead 307s /contact -> /contact/, which would put a
> redirect in front of every page and disagree with the canonical and sitemap
> URLs, both of which are written without a trailing slash.

That is **exactly what production does today**. The config is not being applied
— consistent with there being no `wrangler deploy` script at the repo root.

## 8. Production readiness — what gives it away

1. **A 4 KB HTML document with an empty `<body>`.** View-source shows nothing.
   The loudest signal by far.
2. **862 KB of CSS** for a personal portfolio.
3. **One 1.1 MB JS chunk, zero splitting** across 12 routes.
4. **`.eot` fonts in a 2026 build** — IE11 support on a portfolio.
5. **A live, indexable beta clone linked from the production footer.**
6. **`wrangler.jsonc` documents behaviour the deployment does not have** — a
   comment describing a redirect fix that is demonstrably not in effect.
7. **Config drift** — `README.md` and `CONTEXT.md` credit `vite-plugin-sitemap`,
   which is not a root dependency.
8. **Duplicate case-variant files tracked in git** (`Footer/Index.vue` +
   `Footer/index.vue`).

The **content and metadata layer reads as professional** — the JSON-LD, OG
image handling, and real-404 work are above average for a personal site. The
**delivery layer** is what reads as unfinished.

## Critical fixes

1. **Render actual body content.** Either true SSG (render the Vue app during
   prerender, not just `<head>`) or accept that non-JS crawlers see nothing.
   This gates both the SEO and accessibility scores.
2. **Add an `<h1>` to every route.**
3. **Fix the trailing-slash redirect** so sitemap, redirect target, and
   canonical agree.
4. **Set `VITE_SITE_ENV=beta` in Cloudflare** on the V1 deployment — the fix is
   already in the code and does nothing until the variable exists.
5. ~~**Split the bundle** — lazy-load routes via dynamic `import()`.~~ **DONE** 2026-08-06.

## Important improvements

6. Cut the CSS — audit whether Vuetify earns 862 KB.
7. `Cache-Control: public, max-age=31536000, immutable` on `/assets/*`.
8. Compress the hero (WebP + `srcset`, target <150 KB) and add `width`/`height`.
9. Add CSP, X-Frame-Options, HSTS, Permissions-Policy via a `_headers` file.
10. Drop `.eot`/`.ttf` MDI variants; subset the icon font to glyphs actually used.

## Nice-to-have

11. `<lastmod>` in the sitemap.
12. Self-host Inter to remove the third-party render-blocking request.
13. Drop wildcard CORS on HTML.
14. Fix stale `README.md` / `CONTEXT.md` claims about `vite-plugin-sitemap`.
15. Remove the duplicate `Footer/Index.vue`.

## Quick wins (<10 minutes each)

- **Set `VITE_SITE_ENV=beta` in Cloudflare** ← highest value per minute here
- Add a `_headers` file with the four missing security headers + immutable asset caching
- Merge the duplicate `User-agent: *` group in `robots.txt`
- Drop `.eot`/`.ttf` from the MDI build

## Reproduction commands

```sh
U=https://samyabrata.codeium.xyz

# Headers, robots, sitemap
curl -sSI "$U/"
curl -sS "$U/robots.txt"
curl -sS "$U/sitemap.xml" | grep -c '<loc>'

# Empty-body proof
curl -sS "$U/" | python3 -c "
import re,sys; h=sys.stdin.read()
b=re.search(r'<body.*?</body>',h,re.S).group(0)
t=re.sub(r'<script.*?</script>','',b,flags=re.S); t=re.sub(r'<[^>]+>','',t).strip()
print('body text chars:',len(t)); print('h1 count:',len(re.findall(r'<h1',h)))"

# Redirect / canonical mismatch
curl -sS -o /dev/null -L -w '%{num_redirects} -> %{url_effective}\n' "$U/contact"
curl -sS "$U/contact/" | grep -oE '<link rel="canonical"[^>]*>'

# Asset weight and caching
curl -sSI --compressed "$U/assets/index-Cwd3JTNC.js" | grep -iE 'content-encoding|cache-control'
curl -sS -o /dev/null -w '%{size_download}\n' "$U/assets/index-Cwd3JTNC.js"

# Security headers (expect 0 matches)
curl -sSI "$U/" | grep -icE 'strict-transport-security|content-security-policy|x-frame-options|permissions-policy'

# Beta duplicate is indexable (expect 0)
curl -sS https://beta.samyabrata.codeium.xyz/ | grep -c '<meta name="robots"'
```
